description: 오늘 일일보고서를 카드형 HTML 로 만들어 발행하고 PDF 를 공유드라이브에 올린다
---

일일보고서 스킬(`daily-report`, 플러그인으로 설치했다면 `chan-reports:daily-report`)을 사용해
오늘(YYYY-MM-DD) 보고서를 생성하거나 갱신한다.

그 스킬의 규칙을 그대로 따른다 — 설정(`~/.claude/chan-reports/report-config.json`) 확인,
프레임 채우기, Artifact 발행, URL 인덱스 기록, PDF 변환·업로드.

추가 지시가 있으면 아래를 반영한다: $ARGUMENTS
